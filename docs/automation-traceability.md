## Porción vertical seleccionada

Solicitud sintética del servidor → autorización de sesión/caso/Ventas → lectura de hilo y hechos operativos → identificación de datos faltantes, saldo y dependencias → generación acotada (guion DEMO si no hay proveedor) → borrador revisionado → aprobación humana exacta → ejecución externa bloqueada. El dashboard muestra las lecturas, las dependencias y las excepciones mediante tareas/resultados con evidencia; no acredita acciones externas.

La disponibilidad de chef no impide preparar la venta. Una fuente no conectada conserva estado desconocido. Las alertas de pago sin chef aparecen en la lectura actual del dashboard, sin esperar una conciliación semanal; no se promete entrega fuera de la aplicación. Para reaccionar a pagos reales todavía se requiere un gateway autenticado y un consumidor de eventos autorizado.
